The code

Only a salted hash is stored, never the digits, and the digits are never written to the log. But this page sends the code to the board over your local network without encryption, and three different digits from 1 to 5 are only 60 possible codes.

How to use it

  1. First time: set a code (three different digits from 1 to 5) in "The code".
  2. To open the box: press the Space bar (the button). The LED matrix shows a digit with a dotted line underneath: show that digit to the camera first. Then show your three digits one at a time: hold each number up until the progress dots move on, then make a fist or take your hand away before the next one. A correct code opens the door; it locks again after 10 seconds, or when you press the button.
  3. Wrong code: three wrong tries in a row lock it out for 30 seconds (then longer each time). Being too slow is not counted as a wrong try.
  4. Tamper: if the locked door is forced, the page says TAMPER, finger entry is blocked for 15 seconds, and it is written in the log. It does not count as a wrong try.
